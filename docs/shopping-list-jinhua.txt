WHAT I AM BUILDING
------------------
A self-study EtherCAT industrial-fieldbus project.

  Raspberry Pi  ->  EtherCAT cable  ->  AX58100 slave chip
                ->  SPI  ->  ESP32-S3  ->  motor

The Raspberry Pi is the EtherCAT master. It sends an angle value
every 10 ms. The AX58100 receives it and passes it over SPI to an
ESP32-S3, which drives the motor to that angle.

The servo part already works. I am now adding a NEMA 17 stepper
motor, so I need the motor, a driver, a 12 V supply and a few
small parts.

 Notes to self / 給自己的提醒
---------------------------------------------------------------
 * Item 3 is only the carrier board. Item 2 is the actual driver.
   第 3 項只是載板，第 2 項才是驅動器本體。

 * Install the A4988 the right way round or it dies instantly.
   A4988 方向裝反會馬上燒毀 - 對準 EN 腳位絲印。

 * Fit the capacitor BEFORE the first power-up.
   第一次通電前一定要先裝好電容。

 * Never unplug the motor while 12V is on.
   12V 通電時絕對不要拔馬達接頭。

 * Set Vref with the motor DISCONNECTED.
   調 Vref 時馬達要「拔掉」。
   R100 (0.1 ohm) -> Vref = 0.80 V for 1.0 A
   R050 (0.05 ohm) -> Vref = 0.40 V for 1.0 A

 * Call 02-2392-1111 first to confirm the motor is in stock.
   去之前先打 02-2392-1111 確認馬達有現貨。
